# Normally-off run request and restart prevention

The current circuit turns Kraken PG2 into an isolated 24 V request for one
small relay coil. It does not connect the controller to the cutter's trigger
or arc circuitry. The exact [connection list and calculations](run-interface.json)
are generated by [verify_run_interface.py](verify_run_interface.py).

## Components and connections

Use a **TI SN74LVC1G17DBVR** buffer and **Panasonic AQY212GS** normally-open
PhotoMOS. The buffer uses the controller's 3.3 V supply: pin 5 to 3.3 V, pin 3 to
controller 0 V, pin 1 unconnected. Fit 100 nF directly between supply pins.
PG2 connects through 1 kohm to buffer pin 2; a 10 kohm pull-down from pin 2 to
controller 0 V defines an unplugged-input low. Buffer pin 4 connects through
**154 ohm, 1%, 0.25 W** to PhotoMOS pin 1. PhotoMOS pin 2 returns to controller 0 V.
A 22 kohm, 1% resistor connects across PhotoMOS pins 1/2.

PhotoMOS output pin 4 connects to IF_RUN terminal 13, which receives separately
fused control 24 V C. Pin 3 connects to IF_RUN terminal 14 and K_REQUEST:A1.
K_REQUEST:A2 returns to field 0 V. A 1N4007 directly across this coil has its
cathode at A1. Controller 0 V and field 0 V are separate. There is no other load
on this PhotoMOS output.

The [TI primary data](https://www.ti.com/lit/ds/symlink/sn74lvc1g17.pdf)
supplies the pin assignment and guaranteed output drive used in the screen.
The [Panasonic primary data](https://industry.panasonic.com/ac/cdn/e/control/relay/photomos/catalog/semi_eng_gu1a_aqy21_gs.pdf)
supplies the optically isolated normally-open pinout, recommended LED-current
range, load limits and switching test conditions. This is a schematic-level
design; component isolation ratings do not qualify a finished board for HF
plasma service. Preserve their test conditions when using these calculations.

Calculated LED current spans 5.075 mA minimum to a 23.613 mA conservative maximum
using a zero-forward-drop upper bound. The 154 ohm resistor dissipates at most
0.0851 W. The specified request-coil design cap is 40 mA; output drop using the
catalogue 0.7 ohm maximum is 0.028 V. Cold/hot coil current, switching response,
boot/reset waveforms, board layout, grounding and interference remain actual
hardware verification, not consequences of this arithmetic.

## The request must return low before a restart

Add two **Finder 40.52.9.024.0000** relays with 95.05 sockets:

| Device | Coil supply | Pole 1 | Pole 2 |
|---|---|---|---|
| K_REQUEST | IF_RUN output, independent of machine permission | 11-12 NC allows arming only with request low | 21-24 NO is the tool request |
| K_RUN_ARM | PERMIT through K_REQUEST:11-12, in parallel with its own 11-14 | 11-14 NO holds the arm while PERMIT remains | 21-24 NO permits the request path |

PERMIT is downstream of hardware stop, door, seated head and K_READY. Its loss
removes both K_RUN_ARM and selected tool-coil power. A request held high keeps
K_REQUEST energized, preventing rearming when permission returns. Command
low, allow relays to release, then issue a fresh high. At cold power-up,
K_READY's 12/75-second mode delay allows the request relay to settle first.
This is ordinary relay restart logic, not a monitored safety relay.

The model includes the PhotoMOS catalogue 5 ms / 0.5 ms on/off values at its stated
test conditions. It checks relay pickup 5/10/20 ms and dropout 5/20/50 ms.
Tool fault/recovery tests hold each interruption 300 ms; fill tests use 150 ms.
It does not claim arbitrary short interruptions are latched. Actual suppressed
relay release, temperature, optical response and input glitches need bench
measurement before machinery operation.

PG6 now reports the **combined permission**, through HEAD_SAFE and K_READY's
status pole, so losing stop/door/head permission also reaches the controller.
The second K_READY pole independently gates the hardware tool chain. These
two poles share a relay and are not redundant safety channels.

## Output allocation

K_VFD_RUN and K_TORCH_RUN remain separate, mode-selected gold-contact relays.
Their contacts terminate in floating pairs. Their actual external loads and
required isolation must be checked against the purchased VFD/cutter manuals.
The PhotoMOS here is too slow for 5 kHz speed PWM. The [selected speed converter](SPEED-INTERFACE.md) is a separate channel. The complete
stop/power/brake subsystem, interface PCB and live EMI qualification remain
separate unfinished work. No machine has been energized by these tests.

# Intermediate audit evidence

These files preserve findings from earlier XR1 geometry, before the corrections
described in the main audit. They are not current pass/fail reports. Their source
hashes identify the geometry tested at the time.

Use `../build-check.json`, `../travel-check.json`, `../transfer-check.json` and
`../package-check.json` for the current assemblies and checks. The current travel
checker repeats the exact ledger translation proof; the historical standalone
proof is preserved here for traceability.
